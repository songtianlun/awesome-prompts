# Visual case gallery

These cases are stored as structured data. Each one keeps the original prompt, a Chinese translation, a short usage note, a result image, and a link back to the author.

The older long-form collections stay in the sidebar. The new cases come from the Google AI developer docs (CC BY 4.0) and the OpenAI Cookbook (MIT). Sora 2 result clips are linked from the source and are not stored in this repository.
